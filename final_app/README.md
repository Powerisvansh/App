# DailyTrack – Personal Routine Tracker (Final Release)

## App Overview
DailyTrack is an automatic daily routine and location tracking Android application built using Kotlin, Jetpack Compose, Material Design 3, Room Local SQLite Database, and Google Play Services Location.

- **Zero AI / Zero Cloud Tracking**: 100% on-device private tracking.
- **Accurate Locality & Real Location**: Automatically detects real town and locality names (e.g., Nilokheri, Karnal) and records arrival, stay duration, and departure timestamps.
- **Route Tracking**: Automatically records journeys between places (e.g., Nilokheri → Karnal).
- **Google Maps Navigation Integration**: Tap on any route in the Timeline to inspect start/end points, distance, duration, speed, and tap **"Open in Google Maps"** to launch Google Maps with turn-by-turn directions.
- **Interactive Offline Map**: Smooth gesture canvas map with pan, zoom, visit markers, and route polyline.
- **Data Export & Privacy**: Export tracking records as CSV or JSON; delete individual visits or wipe history anytime.

## File Contents
- `DailyTrack.apk`: Fully compiled, signed debug APK (19 MB), ready to install directly on Android devices running Android 8.0 (API 26) through Android 15 (API 36).

## Installation Instructions
1. Download `DailyTrack.apk` from this folder to your phone.
2. In your phone's File Manager / Downloads, tap `DailyTrack.apk`.
3. Allow "Install Unknown Apps" if prompted.
4. Launch DailyTrack and grant Location permissions to begin automatic routine tracking.
